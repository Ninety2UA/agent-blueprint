# v4.1.1: Agent Blueprint

The body for the GitHub release. A patch to v4.1.0 for one problem in the installer.

- **On a computer with Claude Code's plugin, `install.sh` no longer removes Cursor CLI's marketplace.** On such a computer, 4.1.0 removed Cursor's `agent-blueprint` marketplace, because Cursor reads Claude Code's plugin there. But Cursor keeps marketplaces on your account, and every computer signed in to it shares them. So the removal also reached your other computers, and any of them that installs agent-blueprint through Cursor's own marketplace lost the source it installs and updates from. The installer now leaves the marketplace in place. When the computer also has Cursor's own install, the installer tells you to uninstall that copy in `/plugin`, so Cursor reads only Claude Code's plugin.

## Upgrading

A plugin install updates through its tool (`docs/hosts/<host>.md`). A checkout updates with `git pull`, then `bash install.sh` again. If an earlier run removed Cursor's marketplace and another computer of yours still uses it, add it back once with `cursor-agent plugin marketplace add https://github.com/Ninety2UA/agent-blueprint`.
