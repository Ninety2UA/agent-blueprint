# v4.1.1: Agent Blueprint

The body for the GitHub release. A patch to v4.1.0: the installer no longer changes Cursor's marketplace, which Cursor shares across your computers.

- **`install.sh` no longer removes Cursor CLI's marketplace.** On a computer with Claude Code's plugin, 4.1.0 removed Cursor's `agent-blueprint` marketplace, because Cursor reads Claude Code's plugin there. But Cursor keeps marketplaces on your account, and every computer signed in to it shares them. So the removal also reached your other computers, and any of them that installs agent-blueprint through Cursor's own marketplace lost the source it installs and updates from. The installer now leaves the marketplace in place. If the installer had added Cursor's marketplace on that computer, it now tells you to uninstall Cursor's own copy in `/plugin`, so Cursor reads only Claude Code's plugin. `/plugin` marks Claude Code's copy "(Claude Code)".
- **`install.sh` no longer replaces a Cursor marketplace from another source.** Without Claude Code's plugin, 4.1.0 removed an `agent-blueprint` marketplace that pointed somewhere other than GitHub, such as a checkout or a fork, and added it back from GitHub, which changed the source for every computer on the account. It now leaves that marketplace as it is and prints the two commands that switch it to GitHub.

## Upgrading

A plugin install updates through its tool (`docs/hosts/<host>.md`). A checkout updates with `git pull`, then `bash install.sh` again. If an earlier run removed Cursor's marketplace and another computer of yours still uses it, add it back once with `cursor-agent plugin marketplace add https://github.com/Ninety2UA/agent-blueprint`.
