# v4.0.2: Agent Blueprint

The body for the GitHub release. A patch to v4.0.1 for three problems found while running the site's tutorials.

- **Injection scanners match whole words**: the write scanner (`prompt-guard.js`, on file writes and edits in Claude Code and Codex) and the read scanner (`read-injection-scanner.js`, on file reads in Claude Code) matched a trigger word inside a longer word and reported "Blueprint instructions" (the "print" in Blueprint), "slideshow prompt" and "react as a" as possible prompt injection. Every pattern that starts with a word now needs a word boundary before it. Markdown emphasis such as `_ignore all previous instructions_` is still caught.
- **New projects get `docs/context/DECISIONS.md`**: the scaffolded `AGENTS.md` tells the agent to honor that file and to record conservative choices in it, but `ab-project-start` never created it. It now ships a stub that the `ab-discuss` skill appends to.
- **`ab-brainstorming` shows each design section before asking about it**: in one run it asked for approval of sections whose text never appeared, only their headings. It now writes each section in full in its reply and asks for approval only once every section is shown.

The README also says what the ship runner deletes after it publishes.

## Upgrading

A plugin install updates through its tool (`docs/hosts/<host>.md`). A checkout updates with `git pull`, then `bash install.sh` again. Existing projects need no change: `ab-discuss` creates `docs/context/DECISIONS.md` the first time it records a decision.
