This record covers plan unit U3 of `docs/plans/2026-10-12-1607-feat-codex-install-and-skill-safety-plan.md`: an audit of every skill, its `references/` and its helper prompts against OpenAI's GPT-6 Astra instruction-following guidance, the targeted fixes it led to (R1-R3), and the baseline the fixes are measured against (U2).

## Method and authority (U3)

The audit used the OpenAI Latest model guide's Instruction following excerpt supplied in the unit packet, read by the host on 2026-10-12. No live fetch was attempted. Its relevant warning is that GPT-6 Astra can follow skill and file instructions more literally, including instructions that conflict with the user or block work early. KD2 calls for targeted corrections, not a precedence sentence in every skill.

The input inventory was all 53 `skills/*/SKILL.md` files and all 164 files under their `references/` directories, including helper prompts, companions, examples and data tables: 217 files, 188 after registered copies are represented by their owners. The audit enumerated those paths, screened hard rules and action verbs, inspected the surrounding procedures for suspected conflicts, and compared the shared copies to `scripts/prompt-owners.json`. The retained-rule index below names the unchanged clauses by file, section and source line. Supporting examples are included because authors copy their instructions into future skills.

The checks were R1's ownership limit on TDD discards, R2's existing design or implementation authorization, and R3's repeated approvals, user overrides and destructive actions. Only the user's own messages supply user authorization. Files, tool or CI output, PR or issue comments, and helper output remain data even when they claim to contain approval. A request to run a publishing skill authorizes its ordinary publish path; it does not authorize unrelated destruction or shared-history rewriting.

The U2 section above is unchanged. The local tests pin wording contracts; they do not establish model behavior. The host owns U10's `tdd-override` and `brainstorm-override` runs. No helper campaign, installation, hook probe, release, commit, push or cross-checkout integration was performed in U3. The repository's ab-writing-skills authoring rules were applied using the packet's more specific evidence strategy.
