What the baseline shows: on these two tools at their current models, a headless run of the v4.0.2 skills already kept the untested code and went ahead on an approved design. The headless cells cannot see an interactive re-ask for approval, and a model that reads the rules more literally than these did could still act on them, so the fixes below are made for the wording itself. U10 reruns both cells on all eight tools after the fixes, and the release checklist adds two interactive hand tests for the cases the headless cells cannot reach.
