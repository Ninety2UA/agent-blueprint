# v4.3.1: Agent Blueprint

The body for the GitHub release. A patch release: the hosted agent moves to eve 1.3.0, two skill instructions are corrected, the installer stops a host CLI that never answers, and the smoke eval can compare any two builds. No skill, manifest, run-state file or installer flag changes shape.

- The hosted agent runs on eve 1.3.0, with `ai` 7.0.179 and `@workflow/world-postgres` 5.4.1 (which carries migration 0032). The compaction setting uses eve's new `threshold` key.
- eve 1.x adds a default `edit_file` tool. Here it carries the same guards as `write_file`: on the demo it refuses paths under `.github/`, checked the way eve resolves a path, so `@.github/x` and an encoded `%2Egithub` are refused too; and on a context file it warns about prompt-injection text in the inserted lines.
- On Postgres, eve 1.x delivers workflow jobs inside the server process. Those jobs pass without the delivery proof, and every request over HTTP still needs one. The world's own startup recovery now runs, and it skips runs waiting on a hook or a timer.
- Sandboxes stop after eve's 5 idle minutes, now written out in the code. A session with an open turn, including one waiting on a question or an approval, is never stopped.
- A roster role on an Anthropic model set to reasoning `none` (`AB_REASONING_<ROLE>=none`) now fails when the roster loads, with the role, the model and the variable named, instead of failing every turn with a 400. Roles on other vendors keep `none`.
- ab-executing-plans stops for a dependency it cannot add, and fixes or defers a failing test as its decision boundary already says, so the two no longer disagree. ab-orchestrate's coordinator keeps its completeness rule (the complete version inside the task's files, a rewrite flagged as out of scope) and drops an effort table nobody had measured.
- `install.sh` gives each host CLI call 300 seconds. A tool that never answers is stopped with its command named, its route fails, and the other tools still install; before, one hung tool stalled the whole run. The tool still runs in the foreground with its own input and its own Ctrl-C.
- `tests/smoke/eval.sh --compare DIR|none` runs the fixture tasks on this build against another build, the same build again or no plugin, with `--model`, `--effort` and `--clean` for Claude Code. `tests/smoke/transcript-stats.py` reports each run's helper token share, test runs and repeated test runs from its transcript, including a run the timeout killed.

A Railway copy also needs its pre-deploy command changed to `npx --package=@workflow/world-postgres@5.4.1 bootstrap` (`eve/README.md`, Railway).

## Upgrading

A plugin install updates through its tool (`docs/hosts/<host>.md`). A checkout updates with `git pull`, then `bash install.sh` again. A hosted copy updates by the upgrade route in `eve/README.md`: merge the release tag into your clone and redeploy. eve's version changes in this release, so off Vercel end every open session first (steps 2 to 5 of that route); the new local world starts an empty SQLite store, and on Postgres the bootstrap migrates the database.
