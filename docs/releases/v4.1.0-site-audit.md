# v4.1.0 README and site audit

Plan unit U17 of `docs/plans/2026-10-12-1607-feat-codex-install-and-skill-safety-plan.md`. Read on branch `docs/v4.1-plans` at `9c60564`, then brought up to date at `f5241e4` (after U3, U6, U7, U8, U15b and U16 landed); § Settled since the first read lists what changed.

The README, the eight host notes and every site page were read from source and checked against what 4.1.0 delivers. Most of the install story is out of date. The README, the host notes, the Getting started tabs, the home page and the footer all present a clone plus `bash install.sh` and a shared `~/.agents/skills` copy as the way in, which 4.1.0 replaces with each tool's own command straight from GitHub. The setup skill, `ab-project-start`, is named on several pages, but no page says how to call it in each tool or that Codex offers it after install, and Getting started stops at naming a skill (row G1). Codex has no section of its own: its three steps, the hook trust, what the hooks add and the picker display names are absent. The safer TDD and brainstorming behavior and the onboarding guard appear nowhere yet. The gap list below gives each gap its page, the outdated text, the remedy and the unit that closes it. The install-route table after it is the one statement of each tool's route, so the README, the host notes and both sets of install tabs render the same thing. The placement map proposes two motion pieces, the redrawn eight-tools diagram and no generated raster images, with reasons. A short list of patterns from comparable developer-tool sites closes the file.
