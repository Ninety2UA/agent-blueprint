# v4.0.1: Agent Blueprint

The body for the GitHub release. A patch to v4.0.0 for the installer.

- **Cursor CLI and Amp list each skill once next to Claude Code**: both read Claude Code's plugin as well as `~/.agents/skills`, so on a machine with Claude Code and either of them, `install.sh` no longer writes the shared copy there. Codex gets its own plugin (`codex plugin marketplace add` and `codex plugin add`), Grok Build, Pi and Hermes each get a copy in a folder only they read (`~/.grok/skills`, `~/.pi/agent/skills`, `~/.hermes/skills`; Hermes then needs no config edit), and a shared copy an earlier install left in `~/.agents/skills` is removed: only the skills its install record names, never a folder of your own. The machine decides the route, not `--only`, and a run limited with `--only` keeps the shared copy while another installed tool still reads it. A folder in a tool's skills folder that the installer did not put there is kept, with a warning. Machines without that pair, and `--copy-dir` or `AGENT_BLUEPRINT_COPY_DIR`, keep the one shared copy.

## Upgrading

Update the checkout (`git pull`), then run `bash install.sh` again; it switches the routes and removes the old copy where needed. A plugin install updates through its tool (`docs/hosts/<host>.md`).
