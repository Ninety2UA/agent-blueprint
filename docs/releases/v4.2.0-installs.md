# v4.2.0 install record

Plan unit U12 of `docs/plans/2026-10-28-2249-feat-agent-blueprint-eve-host-plan.md`: the eight coding CLIs install 4.2.0 as they installed 4.1.1, with each skill once, and the installer refuses the hosted option with a pointer to where it is deployed (R20, R21, AE7).

Recorded on 2026-10-29 on macOS, from a clean copy of the product at the 4.2.0 bump laid out as it publishes (the maintainer-only files left out, `AGENTS.md` and its `CLAUDE.md` link at the root), committed in a fresh git repository under `~/.cache/`. The release is not on GitHub yet, so each route ran in its local form, with the copy as the source. The checklist runs each GitHub form once after the publish.

## Method

Codex and Antigravity are the two tools whose install copies the whole plugin folder, so they are the ones a stray `SKILL.md` beside the plugin would reach. Each ran in a fresh profile under `~/.cache/` (`CODEX_HOME` for Codex, `HOME` for Antigravity), nothing written to the real home:

1. The tool's own install command with the copy as the source.
2. Every `SKILL.md` in the installed folder was counted, each skill folder had to appear once, and the installed `skills/` had to equal the copy's `skills/` file for file.
3. The tool's own listing: for Codex, the skill list in the prompt its model receives (`codex debug prompt-input`); for Antigravity, `agy plugin list` and `agy plugin validate`.

The profiles were then deleted.

## The hosted option

`bash install.sh --only eve` exits 2 with `Eve is the hosted option: you deploy it to your own Vercel account, Railway or server instead of installing it here. See https://agent-blueprint.dbenger.com/hosted and eve/README.md.` It refuses the same way in a dry run and when `eve` is named beside another tool, before any tool runs. `bash install.sh --dry-run` with all eight tools on `PATH` finishes with Claude Code, Codex, Antigravity, Grok Build, Pi, Cursor CLI, Hermes and Amp, and no other. Both are held by `tests/gates/test_install.py`.

## The other six tools

Claude Code, Grok Build, Pi, Cursor CLI, Hermes and Amp were not installed again for this record. Their routes and `install.sh` are unchanged since 4.1.1 apart from the refusal above, and their skills are the same files as Codex's and Antigravity's. [The v4.1.0 record](v4.1.0-installs.md) shows each of them installing by its own route with each skill once.
