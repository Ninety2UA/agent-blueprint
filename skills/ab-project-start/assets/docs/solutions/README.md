# Solutions — Institutional Knowledge

Solved problems documented for future reference. Created by the ab-knowledge-compounding skill.

The `learnings-researcher` agent and ab-writing-plans skill automatically search this directory before planning new work.

## Format

Each solution is a markdown file: `YYYY-MM-DD-[slug].md` with YAML frontmatter (title, date, tags, applies-to).

## Creating a New Solution

Run the ab-knowledge-compounding skill with a one-line description after solving a non-trivial problem.
