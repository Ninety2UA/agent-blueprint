# Backlog

Dump anything here: ideas, bugs, tasks, notes. New entries need no structure. The ab-backlog-triage skill sorts them into prioritized items and moves the chosen ones into `docs/context/STATUS.md`.

## Inbox

_Add items here._

## Triaged

_Items that have been reviewed and tagged but not yet started. Priority tags: P0 (this week), P1 (two weeks), P2 (this quarter), P3 (someday). Type tags: [bug] [feature] [research] [chore] [idea]._

Example:

```text
- P2 [feature] Add CSV export to analytics dashboard
- P1 [bug] Login redirect loop on Safari
- P3 [research] Evaluate switching from REST to tRPC
- P2 [chore] Upgrade Node.js to v22 LTS
```

## Parked

_Items explicitly set aside, each with the reason, so they don't keep coming back._

Example:

```text
- [idea] Multi-tenant support — parked until post-launch (see Non-Goals in GOALS.md)
```
